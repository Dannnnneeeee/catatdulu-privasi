Kebijakan Privasi CatatDulu

Berlaku sejak 9 Oktober 2026

Kebijakan ini menjelaskan data apa yang dipakai aplikasi Android CatatDulu, di mana data itu disimpan, dan bagaimana aplikasi memakai akun Google. CatatDulu dibuat oleh ProjectKu.

Ringkasnya

  • Data toko disimpan di HP toko.
  • Kalau toko memakai Google, data hanya dikirim ke Google Drive dan Google Sheet milik akun Google toko sendiri.
  • Pembuat aplikasi tidak menerima, tidak menyimpan, dan tidak bisa melihat data toko.
  • Tidak ada iklan, tidak ada pelacakan, dan tidak ada data yang dijual atau dibagikan ke pihak lain.

Data yang disimpan di HP

Aplikasi menyimpan data yang dimasukkan toko sendiri: produk dan jenisnya, harga, stok dan riwayatnya, transaksi penjualan, serta pengaturan (nama, alamat, dan telepon toko, catatan kaki struk, dan printer yang dipilih). Aplikasi juga menyimpan alamat email akun Google yang dipakai, supaya Pengaturan bisa menampilkan status tanpa internet. Aplikasi membuat salinan database di dalam penyimpanan pribadi aplikasi sebagai pengaman. Semua data ini tidak bisa dibuka aplikasi lain, dan terhapus kalau aplikasi di-uninstall.

Akun Google, Google Drive, dan Google Sheets

Login Google tidak diperlukan untuk memakai aplikasi. Login hanya diminta kalau toko memakai fitur Kirim ke Sheet atau cadangan. Aplikasi meminta satu izin saja:

  • https://www.googleapis.com/auth/drive.file: melihat, membuat, mengubah, dan menghapus hanya file Google Drive yang dibuat oleh aplikasi ini. Aplikasi tidak bisa membuka file lain di Google Drive toko.

Dengan izin itu, aplikasi:

  • membuat dan memperbarui Google Sheet berisi penjualan, rekap, daftar produk, dan riwayat stok, termasuk arsip bulanan;
  • mengunggah cadangan database ke folder cadangan di Google Drive toko, dan memindahkan cadangan lama ke Sampah Drive;
  • membaca daftar file buatannya sendiri, untuk memilih sheet dan memulihkan cadangan ke HP.

Data dikirim langsung dari HP ke Google, tanpa server perantara milik pembuat aplikasi. Aplikasi tidak memakai data Google untuk iklan, tidak menjualnya, tidak memindahkannya ke pihak lain, dan tidak memakainya untuk melatih model kecerdasan buatan. Tidak ada orang yang membaca data tersebut. Penggunaan dan pemindahan informasi yang diterima dari Google API mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use.

Printer Bluetooth

Aplikasi meminta izin "Perangkat di sekitar" hanya untuk menyambung ke printer struk yang sudah dipasangkan di HP. Aplikasi tidak memakai lokasi.

Mencabut akses dan menghapus data

  • Akses aplikasi ke akun Google bisa dicabut kapan saja di myaccount.google.com/permissions. Data di HP tetap ada.
  • Google Sheet, arsip, dan cadangan bisa dihapus langsung dari Google Drive toko.
  • Data di HP terhapus kalau aplikasi di-uninstall atau datanya dihapus di Setelan Android.

Anak-anak

Aplikasi ini untuk pemilik dan pengelola toko, dan tidak ditujukan untuk anak-anak.

Perubahan kebijakan

Kalau cara aplikasi memakai data berubah, kebijakan ini diperbarui lebih dulu, dan tanggal di atas ikut diganti. Perubahan yang memperluas pemakaian data Google akan diberitahukan dan meminta persetujuan toko sebelum berlaku.
